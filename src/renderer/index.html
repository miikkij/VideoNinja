📦 Installation Instructions

Windows:

  1. Download yt-dlp.exe from GitHub Releases
  2. Place it in a folder (e.g., C:\Program Files\yt-dlp\)
  3. Add the folder to your PATH, or
  4. Place yt-dlp.exe in the same folder as VideoNinja

macOS: (Coming Soon)

macOS support is planned for a future release.

For now, you can install yt-dlp via:

brew install yt-dlp
